WebFA UI-1 双窗口预览

控制中心负责长期配置与资源管理；会话监控负责 Agent 实时上网观察、Step-up 和 Human Takeover。两者属于同一个 WebFA Desktop。

窗口一

控制中心

应用设置、Agent、Profile、支付方式、金融额度、文件资源、安全策略与接入配置。

  • 长期配置，不展示实时网页
  • 高权限控制面
  • 为 P12 多 Profile 提供入口
打开控制中心预览
窗口二

会话监控

严格三栏式布局：左栏任务上下文，中栏实时网页，右栏活动、安全状态与待处理事项。

  • 实时观察 Agent 操作
  • Step-up 精确审批
  • Human Takeover 页面接管
